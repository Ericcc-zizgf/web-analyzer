# 網頁分析器 · HTML 結構工作台

以 HTML 結構閱讀為核心。保留深色、綠色重點與圓角卡片，使用固定網頁排版，沒有節點畫布或接線操作。

**[開啟線上版](https://ericcc-zizgf.github.io/web-analyzer/)**

## 使用方式

1. 開啟專案資料夾，選擇一個 HTML 頁面；也可貼上 HTML 或上傳單一 HTML。
2. 點選網頁預覽的元素，左側 HTML 結構會展開祖先並定位；也可從結構反向選取畫面。
3. 查看元素的原始屬性、直接文字、父子層級與來源位置。
4. 切到 HTML 原始碼，查看高亮開啟標籤或瀏覽器解析後的元素片段；可複製、下載 HTML 或匯出結構 JSON。

頁面較多時可搜尋與切換，每次只分析選定頁面。HTML 結構可搜尋、全部展開／收合；預覽預設以 1440 × 900 桌面尺寸排版，再等比例縮進原本的卡片；可切換自適應、平板和手機尺寸。「適合卡片」、放大／縮小與 100% 控制僅調整顯示比例，不會改變所選裝置的排版寬度。放大後可在卡片內捲動，沒有另外開啟全螢幕。

## 畫面分工

- 上方：專案來源、頁面選擇及單頁輸入。
- 左側卡片：HTML 結構搜尋與層級。
- 中間卡片：網頁預覽／HTML 原始碼。
- 右側卡片：所選元素的 HTML 資訊。

較窄螢幕改為兩欄或上下排列，不再使用可拖曳節點、縮放畫布與連線。

## 範圍與限制

- 已移除 CSS 參數編輯、CSS 草稿／歷史／規則追查、JavaScript 語法分析與流程圖、跨檔案符號索引、節點接線與閱讀模式。
- CSS 僅用於還原網頁預覽的外觀；不再提供 CSS 分析介面。來源 JavaScript 不執行，也不建立程式流程圖。
- HTML 原始碼中的 `<style>`、`<script>` 與事件屬性仍是原始 HTML 的一部分，會保留在結構／來源閱讀中。
- 只分析取得的靜態 HTML；由框架或執行時 JavaScript 產生的元素，請先提供建置／匯出的 HTML。
- 預覽不載入外部圖片、字型等網路資源。瀏覽器可能修復 HTML；元素片段與原始檔行號不同。無法唯一對應來源的標籤不猜測高亮位置。
- 資料夾只讀取 HTML 與 CSS，略過套件、建置產物和憑證檔案。單一來源檔案 768 KB、文字合計 16 MB，最多 1,500 份來源。單頁 HTML 上限 2 MB、最多 4,000 個元素。
- 分析不改寫你的原始檔案。

## 線上版與本機版

GitHub Pages 使用 `docs/`；Python 本機服務使用 `frontend/`。兩者共用固定版面與 HTML 工作流程。

線上版可讀資料夾、貼上或上傳 HTML；網址讀取使用 Python 本機版。啟動方式維持 `start.command`，或依現有本機啟動設定執行。

## 閱讀方向

結構樹以較清楚的層級呈現主要語意區塊；搜尋時附上祖先路徑。從預覽選取時會展開祖先並定位，樹狀搜尋中的選取則保留搜尋條件。無法唯一對應原始開啟標籤的元素會明確提示。相同專案資料夾再次開啟時，瀏覽器會記住上次選擇的頁面名稱；仍須由使用者重新選取資料夾，才會讀取任何檔案。

工作區以深色卡片與柔和紫色標示主要操作；桌面同列卡片等高，內容在各自的區域捲動。較窄螢幕使用兩欄或單欄版面。
